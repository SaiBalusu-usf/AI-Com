# Faithful, Game-State-Aware Cricket Commentary Generation

A data-to-text study for CAP 6640 (graduate NLP). Given a structured
ball-by-ball cricket event record, generate one-to-three sentences of English
commentary — and measure, with a slot-level fact checker, how faithful each
generation approach stays to the structured input.

**Research questions**

- **RQ1 Faithfulness:** template vs. few-shot-prompted vs. fine-tuned
  generation, measured by slot-level fact-checking against the structured
  input (hallucination rate, omission rate, per-slot precision).
- **RQ2 Game-state conditioning:** do match-tension features (required run
  rate, wickets in hand, phase) measurably improve excitement calibration?
- **RQ3 Efficiency:** can a fine-tuned ≤1.5B model match a large prompted
  model on faithfulness at <1 s/ball?

## Setup and one-command repro

```bash
make venv && . .venv/bin/activate   # optional but recommended
make setup      # core stack (data + eval harness + template baseline), CPU-only OK
make repro      # tests -> fixture -> golden-path run -> tables -> figures (<5 min)
```

`make mini` alone runs the golden path: committed 200-row fixture → template
baseline → full evaluation harness → run directory with `metrics.json` +
`report.md` (~2 s on a laptop CPU).

The neural systems (B2 few-shot, M1/M2 fine-tunes, BERTScore, the excitement
model head, spaCy NER) additionally need:

```bash
make setup-full   # torch/transformers/peft/trl/bert-score
make setup-cuda   # + bitsandbytes, CUDA machines only
python -m spacy download en_core_web_sm
```

On CPU-only machines install torch from the CPU wheel index first — see the
note at the top of `requirements-ml.txt`.

## Evaluation harness

Every system is scored by the identical pipeline
(`cricket_commentary.eval.harness.evaluate`):

- **Faithfulness** (`eval/factcheck.py`): regex+lexicon slot claims (runs,
  boundary, wicket+kind, attribution, team/personal score, milestones)
  verified against the record and cumulative state. v2 after an adversarial
  review that found nine classes of wrong verdicts on everyday commentary —
  every repro sentence is now a regression test (see EXPERIMENTS.md).
  Reports hallucination rate, omission rate vs. a reference-omission
  baseline, per-slot precision, and mention recall.
- **Excitement** (`eval/excitement.py`): heuristic + (optional) emotion-model
  score, validated on references (Spearman vs. salience × tension) **before**
  it is ever applied to generations; failed validation blocks calibration.
- **Surface**: sacreBLEU, ROUGE-L, BERTScore (recorded unavailable when the
  model cannot be fetched — never silently skipped).
- **Diversity**: per-innings distinct-1/2, symmetric self-BLEU, and the
  consecutive-ball phrase-recycling rate ("EA Sports repetition").
- **Latency**: p50/p95 per ball + tokens/sec at batch 1 after warmup, with
  hardware context.

## Limitations

- All current numbers come from synthetic matches and synthetic references
  (bounded vocabulary → diversity metrics are optimistic; excitement/tension
  correlation is by construction).
- The fact checker is precision-first: team-milestone claims and some idioms
  are deliberately unchecked (documented in `eval/factcheck.py`), and its
  invented-player check needs the optional spaCy model.
- Latency comparisons across machines are not meaningful; each run records
  its hardware context.
- B2/M1/M2 numbers await D1–D3; figures/tables pick them up automatically.
